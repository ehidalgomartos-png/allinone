Cookies and local storage policy

Technologies currently used by Instant Admirers.

Version 1.020 September 2026

This English version is provided for convenience. The Spanish version is the reference version.

1. Current situation

In the current version of Instant Admirers, advertising cookies, advertising networks, Meta Pixel, and Google Analytics have not been integrated. The application uses browser local storage for technical functions and preferences requested by the user.

2. Technologies used

TechnologyPurposeDuration
localStorage: tokenKeep the user signed in. The authentication token has a maximum lifetime of 30 days and is removed from local storage when the user logs out.Until logout, manual browser deletion, or functional expiry of the token.
localStorage: feedModeRemember whether the user prefers the “Following” or “For You” feed.Until the user changes the preference or clears browser data.
localStorage: iaLanguageRemember the interface language chosen by the user.Until the user changes the language or clears browser data.

3. Strictly necessary technologies

Technologies strictly necessary to provide a service expressly requested by the user may be used without specific cookie consent. Therefore, while Instant Admirers is limited to the technical technologies described in this policy, no consent banner for non-essential cookies is shown.

4. If analytics or advertising is introduced

Before activating non-essential cookies or equivalent technologies, we will update this policy and, where applicable, implement a consent mechanism that allows users to accept and reject at the same level, prevents non-essential technologies from loading before a valid choice, and makes it easy to withdraw that choice.

5. How to clear storage

You can log out of Instant Admirers to remove the token from local storage. You can also clear site data from your browser's privacy settings.
