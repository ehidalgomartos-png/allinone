# Instant Admirers V1.12.12 — Full Image Viewer

Base directa: V1.12.11.

## Qué cambia

- Las fotos de publicaciones y republicaciones dejan de recortarse con `object-fit: cover` y se muestran con `contain`.
- Al pulsar una foto se abre un visor de pantalla completa que enseña la imagen entera.
- El visor funciona en escritorio y móvil y se cierra con ×, pulsando fuera o con Esc.
- Las imágenes protegidas conservan bloqueo de menú contextual, arrastre y marcas de agua.
- Las imágenes compartidas por mensajes también pueden abrirse completas cuando el usuario tiene acceso.
- No cambia Bunny, Growth Engine, SEO, PostgreSQL ni las reglas de acceso.
