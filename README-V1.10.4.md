# Instant Admirers V1.10.4 — Sin “Rompe el hielo”

Esta versión parte de V1.10.3 y mantiene todas sus mejoras de publicidad, cuenta Administrador técnica y migraciones.

## Cambio principal
- Eliminado el bloque “ROMPE EL HIELO / Empieza una conversación” del feed de Inicio.
- Eliminado el mismo bloque de Descubrir.
- Eliminada la opción “Ideas para publicar” y su vista previa de Administración → Comunidad inicial.
- No se reserva ningún hueco donde antes aparecía el bloque.

No hay cambios destructivos en PostgreSQL. Las columnas históricas relacionadas con prompts se conservan por compatibilidad.
