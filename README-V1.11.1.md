# Instant Admirers V1.11.1 — Contenido protegido por acceso

Parche de privacidad sobre V1.11.0. Un perfil con **Acceso especial** activo puede seguir siendo descubierto para que el usuario vea y complete el reto, pero su contenido social queda oculto hasta que el visitante tenga acceso.

## Regla
Una publicación de un perfil con reto activo es visible únicamente si se cumple al menos una condición: el visitante es el autor, el reto está desactivado, ambos son amigos o el visitante ya ha completado el número de referidos requeridos (y los requisitos adicionales configurados). Después siguen aplicándose privacidad de cuenta, bloqueos, silencios y visibilidad de la publicación.
