# Actualizar a V1.12.35

1. Parte de una instalación **V1.12.34**.
2. Sube el contenido de `Instant-Admirers-V1.12.35-PATCH-GitHub.zip` respetando las rutas.
3. Despliega/reinicia el servicio en Render.
4. Comprueba `/api/health` y confirma `version: "1.12.35"`.
5. Abre una publicación con comentarios y Me gusta. Deben aparecer hasta 3 comentarios bajo la publicación y el resumen de quién ha dado Me gusta.
6. Pulsa el resumen de Me gusta para abrir la lista completa.

No hay migración manual de base de datos para esta versión.
