# Instant Admirers V1.12.23

Hotfix SEO sobre V1.12.22. Corrige la sobrescritura en cliente de los metadatos dinámicos de perfiles públicos detectada mediante Google Search Console.

El HTML inicial y el DOM tras ejecutar JavaScript conservan el title, description, Open Graph, Twitter Cards, canonical y JSON-LD específicos de cada perfil. Los anfitriones virtuales continúan identificados de forma visible y estructurada como personajes virtuales gestionados por Instant Admirers.
