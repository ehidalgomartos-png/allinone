# Instant Admirers V1.12.38

**Emails inteligentes / recuperación de usuarios**

Esta versión parte de **V1.12.37.2 estable** y añade una capa inteligente sobre los avisos sociales por email de V1.12.36.

La app evita enviar correos sociales mientras la persona está conectada o acaba de usar Instant Admirers, limita ráfagas de Me gusta/seguimientos, agrupa actividad pendiente en resúmenes y añade recordatorios de vuelta opcionales para usuarios inactivos.

Los recordatorios de reactivación están **desactivados por defecto** y solo se usan si el propio usuario los activa desde Ajustes de cuenta.

`/api/health` debe devolver `version: "1.12.38"`.
