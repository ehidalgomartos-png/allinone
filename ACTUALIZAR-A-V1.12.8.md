# Actualizar a Instant Admirers V1.12.8

V1.12.8 no necesita migraciones ni nuevas variables de entorno.

## Pasos
1. Sube el contenido completo de este paquete a GitHub sustituyendo la versión anterior.
2. Deja que Render despliegue el commit.
3. Abre `https://instantadmirers.com/api/health`.
4. Confirma que aparece `"version":"1.12.8"`.
5. Crea o copia un enlace activo desde **Administración → Growth Engine**.
6. Ábrelo en una ventana privada/no autenticada.
7. Comprueba que encima de las pestañas Entrar / Crear cuenta aparecen:
   - cabecera;
   - avatar;
   - nombre;
   - frase de perfil;
   - biografía.
8. Cambia de Entrar a Crear cuenta y confirma que la vista previa permanece.
9. Completa un login de prueba y confirma que se abre el perfil destino.

## Sin cambios
No modifiques las claves Bunny, PostgreSQL, Resend ni Cloudinary legacy para esta actualización.
