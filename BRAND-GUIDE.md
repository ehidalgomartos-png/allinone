# Instant Admirers — Guía de marca V1.1.1

## Identidad

- **Marca:** Instant Admirers
- **Nombre corto:** Admirers
- **Dominio principal:** `instantadmirers.com`
- **Tagline:** **Conecta. Comparte. Descubre.**
- **Mensaje principal:** Tu comunidad para compartir lo que eres y descubrir a tu gente.

## Colores

- Fondo principal: `#090A0F`
- Panel: `#12141D`
- Fucsia: `#FF2D9A`
- Violeta: `#7C3CFF`
- Texto principal: `#F7F7FB`
- Texto secundario: `#969CAB`

## Logo

Los recursos están en `public/assets/brand/`:

- `instant-admirers-logo.svg` — logo horizontal vectorial
- `instant-admirers-logo.png` — logo horizontal PNG
- `instant-admirers-mark.svg` — isotipo vectorial
- `favicon-16.png`
- `favicon-32.png`
- `apple-touch-icon.png`
- `icon-192.png`
- `icon-512.png`
- `og-card.png` — imagen 1200×630 para compartir enlaces

El símbolo representa dos personas conectadas formando un corazón. El punto superior funciona como destello/actividad.

## Uso recomendado

- Fondo oscuro siempre que sea posible.
- No estirar ni deformar el isotipo.
- No cambiar el degradado principal salvo que se actualice toda la identidad.
- En móvil puede mostrarse el isotipo + “Instant Admirers”; para espacios muy pequeños se puede usar solo el isotipo.
