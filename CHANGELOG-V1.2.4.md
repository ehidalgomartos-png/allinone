# V1.2.4 — Doble invitación y acceso a perfiles

- Dos invitaciones separadas: normal y directa a perfil.
- Redirección automática al perfil compartido tras login/registro.
- Perfil especial bloqueado hasta completar el número de referidos.
- Mensaje `Te quedan X para poder ver este perfil`.
- El usuario puede seguir usando toda su cuenta durante el reto.
- Los referidos del reto crean su propio perfil normal.
- Posts, Stories, Reels y datos detallados del perfil quedan protegidos hasta el desbloqueo.
- Textos de WhatsApp específicos para cada tipo de invitación.
