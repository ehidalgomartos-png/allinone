# Instant Admirers V1.12.41

**Gestión visual de perfiles virtuales 2.0**

Esta versión convierte la biblioteca visual de los 100 perfiles virtuales en un editor de mantenimiento diario. El importador masivo sigue siendo la herramienta para cambios grandes; Gestión visual permite corregir un perfil o una sola imagen sin rehacer el lote completo.

## Flujo principal

Administración → Comunidad virtual → perfil → **Gestión visual**.

Desde ahí puedes ver las imágenes activas/retiradas, sustituir una foto, cambiar avatar o portada, reordenar el pool de publicaciones, retirar/restaurar imágenes, detectar duplicados exactos conocidos y consultar/deshacer el último cambio reversible.
