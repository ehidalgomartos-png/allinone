# Instant Admirers V1.6.0

Versión orientada al lanzamiento controlado. Mantiene PostgreSQL, Cloudinary, Resend, rendimiento V1.4 y PWA V1.5, y añade herramientas para incorporar usuarios reales por fases sin generar perfiles ficticios.

El modo de registro inicial es `open`. Desde Administración se puede cambiar a `invite_only` o `paused`.
