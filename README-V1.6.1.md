# Instant Admirers V1.6.1

Extensión de V1.6 para pruebas previas al lanzamiento.

Incluye un laboratorio administrativo que crea contenido sintético temporal y claramente marcado como `TEST`, suficiente para validar paginación, scroll infinito, Descubrir, Reels, Stories, mensajes y recomendaciones. Todo el conjunto puede eliminarse con un botón sin afectar a usuarios reales.
