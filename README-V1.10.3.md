# Instant Admirers V1.10.3 — Texto visible en publicidad

Esta versión parte de V1.10.2.

## Novedades
- Los banners de imagen pueden mostrar título, texto y llamada a la acción visibles.
- El texto alternativo queda claramente separado como campo de accesibilidad y no se presenta como copy comercial.
- Los anuncios existentes creados antes de V1.10.3 reutilizan temporalmente su `alt_text` como texto visible hasta que se vuelvan a guardar desde Administración.
- El bloque de texto se adapta a columna derecha, feed y perfiles.
- Si título, texto y botón están vacíos, el anuncio continúa siendo solo imagen, sin hueco extra.
