# Instant Admirers V1.8.0

## V1.8 — Comunidad inicial real

Esta versión prepara Instant Admirers para una primera cohorte real sin rellenar la red con perfiles ficticios.

### Novedades
- Warm-start en Inicio con ideas de conversación cuando hay poco contenido.
- Bloque “Recién llegados” en Descubrir, limitado a cuentas reales y verificadas.
- Indicador de comunidad durante Cohorte inicial/Público.
- Distintivo de miembro fundador para las primeras cuentas reales (límite configurable).
- Panel “Comunidad inicial” en Administración.
- Métricas de miembros reales, activados, posts y actividad reciente.
- Configuración independiente para prompts y spotlight de recién llegados.
- No se crean perfiles ni publicaciones falsas.

Base: V1.7.1.
